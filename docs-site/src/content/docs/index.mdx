# Runenwerk

Runenwerk is the Dornglut integration platform and reference engine: it combines the
standalone Runen-family frameworks into a usable product, editor, runtime, and
developer surface. This site is the public guide to the current repository.

are published through the separate Reference navigation group. Start with the
[Runenwerk platform architecture](architecture/runenwerk-platform-architecture.md)
or the [ADR index](adr/README.md) when you need the reasoning behind a current
boundary.

content.
