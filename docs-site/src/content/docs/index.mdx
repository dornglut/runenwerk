# Runenwerk

Runenwerk is an experimental Rust platform for building native applications, games,
development tools, and simulations. It integrates the standalone Runen-family frameworks.

## What would you like to do?

### Build an application

Use the current Engine APIs to run a windowed or headless Rust application, then add
UI, rendering, or simulation as needed.

[Get started with the Engine](engine/reference/usage-guide.md)

### Explore examples

Run existing examples, from minimal runtime setup and window input to Boids and SDF rendering.

[Browse examples](engine/examples/overview.md)

### Understand Runenwerk

Learn how applications, the Engine, domains, and standalone frameworks fit together.

[Explore the platform architecture](architecture/runenwerk-platform-architecture.md)

Runenwerk is under active development. Its public APIs are not yet stable.
